# Prompts: plan

## Set up the repo and add PLAN.md

```
I'm building Bar Hop SF for a class assignment. Read PLAN.md first. I've also attached the assignment for reference.

Rules for this whole project (save them in CLAUDE.md):
- Never commit directly to main. Every change goes through a GitHub Issue,
  a feature branch, and a pull request whose description includes "closes #N".
- One feature per branch and PR, in the order listed in PLAN.md section 2.
- For each feature, save my key prompts in prompts/<feature>.md on that branch.

Right now, only do the first PR:
1. Create a public GitHub repo called bar-hop-sf and push an initial commit.
2. Open an Issue titled "Add PLAN.md".
3. Create a branch called docs/plan, add PLAN.md and CLAUDE.md, and save
   this prompt in prompts/plan.md.
4. Open a PR into main that closes the Issue.
Don't write any app code yet.
```
